# Self-hosted fonts

These files are served locally from `/fonts/` so the app never waits on a
third-party font CDN at first paint. All three families are released under
the SIL Open Font License 1.1, which permits embedding in a website.

| File pattern | Family | Designer | Licence |
|---|---|---|---|
| `fraunces-*-latin.woff2` | Fraunces (display serif) | Undercase Type | OFL 1.1 |
| `sourcesans-*-latin.woff2` | Source Sans 3 (body sans) | Adobe | OFL 1.1 |
| `plexmono-*-latin.woff2` | IBM Plex Mono (data mono) | IBM | OFL 1.1 |

Source of the binaries: Google Fonts (`fonts.gstatic.com`), latin subset only.
Licence texts: <https://openfontlicense.org/> ·
Fraunces: <https://github.com/undercasetype/Fraunces> ·
Source Sans 3: <https://github.com/adobe-fonts/source-sans> ·
