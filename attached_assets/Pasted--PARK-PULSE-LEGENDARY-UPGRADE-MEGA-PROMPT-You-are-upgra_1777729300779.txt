## ➕ NEW DATA FILES TO INTEGRATE

Add these two new datasets to the `/data/` folder and integrate them fully into the explore page with their own filter toggles, map markers, popups, and sidebar cards:

### 1. `data/npws-facilities-greater-sydney.geojson`
National Parks & Wildlife Service facility points across Greater Sydney.
- **1,795 features** with properties: `AssetName`, `d_SubtypeC` (facility type), `d_Branch` (area), `d_LGA`, `Comments`
- Facility types include: `Picnic Table`, `Seat`, `BBQ/Fireplace`, `Shelter`, `Waste/Recycling Stn`, `Bin`, `Playground Equipment`, `Cycle Rack`, `Life Buoy Stand`
- Coordinates are in the `geometry.coordinates` array as `[lng, lat]`
- **Filter label:** "NPWS Facilities" with subtypes (BBQ, Picnic, Shelter, etc.)
- **Marker colors by subtype:**
  - BBQ/Fireplace → `#FF6B35` (orange-red)
  - Picnic Table → `#8B5E3C` (brown)
  - Shelter → `#5B8C5A` (green)
  - Playground Equipment → `#E91E8C` (pink)
  - Seat → `#6B8CBA` (steel blue)
  - Everything else → `#888` (grey)
- Use clustering (MarkerCluster) for this layer
- Popup should show: facility type badge, AssetName, d_LGA, d_Branch, Comments

### 2. `data/Dog_off-leash_parks.geojson`
City of Sydney off-leash dog areas.
- Properties: `ParkName`, `Street`, `Suburb`, `Postcode`, `Agency`, `OffLeashTime`, `ProhibitedAreas`, `OffLeashDescription`
- Geometry is `Point` with `[lng, lat]` coordinates
- **Filter label:** "🐕 Dog Parks"
- **Marker:** Bright yellow-green `#AACC00` circle with a paw icon (SVG inline)
- Popup shows: park name, suburb, off-leash hours, prohibited areas, full description
- If `OffLeashTime === "At all times"` → show green badge "Always Off-Leash"
- Otherwise → show orange badge with the time restriction

## 🐛 BUGS & GLITCHES TO FIX

Fix all of the following in the existing code:

1. **`toilets-sydney.json` and `trees.geojson` are empty (0 bytes) in the original repo.** Either populate them with real data OR gracefully handle empty/missing files without crashing or showing errors. Add fallback empty-state messages like "No data available for this layer."

2. **`parks-suburbs.json` is also empty.** The `loadParkData()` function tries to merge suburb data — make this graceful so it doesn't break when the file is empty.

3. **Map doesn't invalidate size properly on sidebar resize.** The sidebar resize handle works but the map tiles don't redraw correctly on slow drag. Call `map.invalidateSize()` continuously during drag, not just on mouseup.

4. **Mobile menu toggle** (`mobile-menu-btn`) works but the nav doesn't close when you click a link or click outside it. Add a document click listener to close the nav on outside click.

5. **Filter clear button doesn't reset the Blacktown layer.** When "Clear Filters" is clicked, the Blacktown layer (which auto-loads on startup) gets removed but is never re-added. Fix: Blacktown layer should always be visible; clear filters should not remove it.

6. **Park modal has no directions button.** When a park popup or modal opens, add a "Get Directions" button that opens Google Maps to that lat/lng in a new tab: `https://www.google.com/maps/dir/?api=1&destination={lat},{lng}`

7. **Search doesn't find parks by suburb.** The search only checks park name. Extend it to also search suburb, park type, and facility tags.

8. **Empty state for zero filter results** shows generic message. Improve it to say which filters are active and suggest clearing them.

9. **Explore page on mobile** — the sidebar overlaps the map on small screens and there's no way to dismiss it. Add a proper mobile drawer behaviour: sidebar slides up from bottom on mobile, tap outside to dismiss.

10. **No loading indicator** for the initial park data load. Users see a blank map for a moment. Add a subtle loading spinner or skeleton state.
